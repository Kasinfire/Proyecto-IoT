Guía breve para el WebSocket de prueba

Esta página escucha JSON plano desde el servidor WebSocket que configures. La demo no descifra AES-GCM, no envía simulaciones y no acciona MQTT.

  1. Ranita: {"nodo":"ranita","tipo":"sombra","nivel":60}
  2. Gatito: {"nodo":"gatito","tipo":"nota","nota":"mi","vel":90}
  3. Pollito: {"nodo":"pollito","tipo":"agitar","intensidad":70}
  4. Estado explícito: {"nodo":"ranita","tipo":"estado","estado":"online"}

nivel e intensidad son nombres de ejemplo; acuerda el formato con quien haga el flujo.
